# DOSBox source and licenses

Retro Desktop 98 bundles the DOSBox and ZIP WebAssembly files and browser library from [emulators 8.3.8](https://www.npmjs.com/package/emulators/v/8.3.8). Android uses these published files directly from `app/src/main/assets/dosbox/engine/`. The same directory includes the GPL license text. The player that controls the engine is in `app/src/main/assets/dosbox/`.

- `emulators-8.3.8.tar.gz` contains the [v8.3.8 source](https://github.com/js-dos/emulators/tree/v8.3.8), including the libzip fork, licenses, and upstream build scripts. Unused DOS benchmark executables and their generated byte arrays were omitted from this archive.
- `dosbox-98d1639.tar.gz` contains the [exact DOSBox revision](https://github.com/js-dos/dosbox/tree/98d1639f66ec91652f5661cf2f4df689721a73e0) pinned by that release, including authorship and its GPL-2.0-or-later terms.

To rebuild the vendor files, extract the emulators sources and unpack the DOSBox archive into its `native/dosbox` directory, stripping the archive's top-level directory. The upstream `Dockerfile`, `CMakeLists.txt`, and `gulpfile.ts/` use Emscripten 3.1.28 and Yarn. For the upstream full build, fetch the other submodules at the revisions recorded in the v8.3.8 source tree. The launcher uses the `wdosbox` and `wlibzip` WebAssembly targets and `emulators.js`. It does not package the separate DOSBox-X engine.
